# Repository instructions

- Place all new documentation in the `docs/` folder in the first instance, unless explicitly instructed otherwise.
- Never change the `.gitignore` file.
- To preview the site, run `bash serve.sh` from the repository root. This starts a Python HTTP server at `http://localhost:8000/`; open that URL rather than opening `desktop.html` directly, because `index.html` loads the app scripts, styles, and event data. Use a browser width of at least 768px for the desktop calendar. Stop the server with Ctrl+C.
